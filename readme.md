# 猜数字小游戏

程序随机想一个整数，你来猜，程序只告诉你「大了」还是「小了」，
直到猜中为止，并统计你一共猜了多少次。

这个项目有两个版本：**网页版**（点开就能玩，带难度与排行榜）和 **Python 版**（命令行）。

### 在线玩

👉 **https://hagxybu123.github.io/guess-number-game/**

打开就能玩，手机电脑都行，不用装任何东西。
也可以直接在你个人主页的作品区里点「直接在这里玩」，不用跳转。

### 功能

**玩法**

| 功能 | 说明 |
| --- | --- |
| 三档难度 | 简单 `1~50` / 普通 `1~100` / 困难 `1~500`，每档独立记录最佳成绩 |
| 范围自动收窄 | 每猜一次告诉你「现在只剩 37~62，还剩 26 个可能」 |
| 接近提示 | 差 3 以内「非常接近了」，差 10 以内「有点接近」 |
| 猜测记录 | 猜过的数字都留着，↑ 猜大 / ↓ 猜小 / ✓ 猜中 |
| 本档最佳 | 每一档分别记住最少猜中次数 |

**排行榜**

| 功能 | 说明 |
| --- | --- |
| 全站排行榜 | 猜中后可以留名字上榜，数据存在云端，别人也能看到 |
| 分难度榜 | 每个难度一张榜，各显示前 8 名 |
| 断网降级 | 云端连不上时自动退回本地记录，并明确告知「这条只记在了本机」 |

**健壮性**

| 功能 | 说明 |
| --- | --- |
| 非法输入处理 | 空值、非数字、超范围、**已经被排除掉的数** 都会被拦下并说明原因 |
| 全角数字兼容 | 手机输入法打出的 `１２３` 自动转成 `123` |
| 键盘操作 | 输入框按 `Enter` 直接提交 |
| 减少动效 | 系统开启「减少动态效果」时自动关闭所有动画 |
| 移动端适配 | 窄屏重新排版，输入框与按钮加大便于点按 |

### 实现说明

- **零依赖**：单个 `index.html`，没有框架、没有构建步骤
- **纯 CSS 视觉**：星空背景用 `radial-gradient` 平铺，**不使用 canvas**
  （部分国产浏览器内核上 canvas 绘制不可靠，这个项目刻意避开了）
- **动效只用 `transform` / `opacity`**：避免逐帧重绘导致的闪烁
- **排行榜后端**：`textdb.online`（无需注册、CORS 可用），写入失败自动降级到 `localStorage`

## 🐍 Python 版

命令行版本，源码在 [`game.py`](game.py)。

### 运行方式

1. 确认电脑装了 Python 3（终端里执行 `python --version` 能看到版本号即可）
2. 打开终端（Windows 是 `cmd` 或 PowerShell），切换到本项目所在的文件夹
3. 执行：

```bash
python game.py
```

4. 按提示输入 1~100 之间的整数，回车提交

### 示例输出

```
====猜数字游戏====
我已经想好1~100之间一个数字，你来猜！
请输入你的猜测：50
大了
请输入你的猜测：25
小了
请输入你的猜测：37
恭喜！猜中了！一共猜了3次
```

### 用到的语法

- `random.randint(1, 100)` —— 生成随机整数
- `while True` + `break` —— 一直循环直到猜中
- `try / except ValueError` —— 处理输入了非整数的情况
- `f-string` —— 把猜测次数拼进提示语里

## 🧠 一点小心得

猜数字这题最容易忽略的不是"怎么判断大小"，而是**边界情况的处理**：

- 已经猜过 80 且提示"大了"，那 81~100 就都排除了，再猜这些数应该直接拦下而不是白费一次机会
- 用户可能输入的是一堆奇奇怪怪的东西：空值、字母、全角数字、超出范围的大数
- 网络可能随时断，写排行榜要保证"我玩过"这件事不会因为网络问题凭空消失

网页版里这些都处理了，也都有对应的测试（见仓库的提交记录）。
